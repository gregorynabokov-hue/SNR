# Спецификация ИИ-сценариев СНР OS

## Главное правило
GitHub Pages — статический хостинг. Ключи API в браузере хранить нельзя: их увидит любой. Все запросы к ИИ идут через серверный прокси, который держит ключи и применяет лимиты.

## Поток данных
1. Клиент (PWA) отправляет прокси **сводку профиля**, а не сырые данные:
   - уязвимость по четырём спектрам, %;
   - пульс покоя и восстановления;
   - средний дискомфорт по спектрам;
   - номер дня курса и протокол;
   - тренд за последние 5 сессий (знак и величина, без точек).
2. Прокси формирует промпт и просит у языковой модели **только JSON** по схеме ниже.
3. Прокси валидирует JSON по схеме и правилам безопасности. Если не прошёл — берётся локальный шаблон.
4. Для каждого сегмента прокси запрашивает картинку и звук. Результаты кэшируются по хэшу промпта.
5. Клиент проигрывает сценарий. Если медиа не пришло за лимит времени, сегмент играет локально.

## Схема сценария
```json
{
  "title": "string, до 60 символов",
  "duration_s": 180,
  "protocol": "shield | booster | peak | reset",
  "segments": [
    {
      "t_start": 0,
      "t_end": 60,
      "kind": "breath | ambient | task | rest",
      "intensity_target": 0.3,
      "image_prompt": "string, без имён и узнаваемых людей",
      "audio_prompt": "string",
      "stop_if": { "hr_rise_pct": 15, "discomfort_gte": 7 }
    }
  ]
}
```

## Правила безопасности (зашиты в код, не в промпт)
- `intensity_target` не выше 0.7 и не выше текущего порога пользователя.
- Мерцание: не чаще 3 Гц, без красного на тёмном фоне.
- `stop_if` обязателен у каждого сегмента. Срабатывание снижает нагрузку или завершает сессию.
- Запрещены тексты с диагнозами, лечением, обещаниями излечения, а также упоминания медикаментов.
- Картинки и звук не должны содержать людей и лиц, изображения детей запрещены.
- Ответ модели проверяется на схему. Всё, что не проходит, отбрасывается.

## Промпт (черновик)
Системная часть: «Ты создаёшь короткий сценарий для тренировки спокойствия. Отвечай только JSON по схеме. Не ставь диагнозов и не давай медицинских советов. Не используй людей и лица в описаниях картинок.»
Пользовательская часть: сводка профиля из раздела «Поток данных» и текущий протокол.

## Что не делаем
- Не отправляем в модель имя, возраст точно, номер телефона и сырые пульсовые ряды.
- Не сохраняем тексты сценариев на сервере дольше 30 дней.
- Не используем сценарии как диагноз или рекомендацию к лечению.

## Открытые вопросы
- Какой провайдер текста, картинок и звука выбираем (стоимость, условия хранения данных, доступ из России).
- Лимит запросов на одного пользователя в день.
- Нужна ли регистрация или достаточно анонимного идентификатора устройства.
